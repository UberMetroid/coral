Engineered for Kelp, Reef, Shoal & Modern GNOME

Derived from Alphabetical App Grid by Stuart Hayhurst and upgraded with smart overflow prevention and Kelp/Reef folder borders.

Smart Overflow Page Prevention

When top-level icons exceed a single page (default 24), Coral inspects Freedesktop .desktop Categories and groups enough categories into labeled folders so your entire App Grid stays on Page 1.

Alphabetical Grid & Folders

Automatically sorts both the top-level App Grid and the icons inside every App Folder (org.gnome.desktop.app-folders), with Z -> A reverse mode and configurable folder placement.

Kelp & Reef Folder Accent Borders

Styles open App Folder popups with a customizable accent border and 1-click presets (Gruvbox Amber, Kelp Emerald, Ocean Cyan, Coral Red).

Quick Install

Install from the latest GitHub Release bundle across Fedora, Debian, Ubuntu, Arch, openSUSE, and NixOS:

gnome-extensions install --force coral@ubermetroid.github.io.shell-extension.zip
gnome-extensions enable coral@ubermetroid.github.io
